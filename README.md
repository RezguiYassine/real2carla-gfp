# Real2CARLA-GFP companion site

Source of https://rezguiyassine.github.io/real2carla-gfp/, the companion page of
*Real2CARLA-GFP: Reconstructing Real Traffic Accidents in CARLA from
Uncalibrated CCTV Video*. It shows real accident clips from the CADP dataset
next to their CARLA reconstructions from six views, the iteration history of
one accident, three failure cases, and downloadable scenes.

The page is static. `index.html` and everything under `static/` are built
locally and committed; the workflow in `.github/workflows/pages.yml` only
publishes them.

## Layout

```
index.html                  generated by tools/build_site.py (do not edit)
site_src/
  site.yaml                 title, authors, links, BibTeX
  accidents.yaml            the accidents the page shows (the manifest)
  index.html.j2             page template
  real_spans.json           written by encode_clips.py: where each real clip has footage
static/
  css/ js/ images/
  videos/<video-N>/         real + six views, poster per clip; history/; teaser.mp4
  data/<video-N>.json|zip   plot data and scene downloads
tools/
  render_extra_views.py     CARLA: ego camera + semantic LiDAR on each crash vehicle
  encode_clips.py           cut every clip to the window around contact, H.264
  make_teaser.py            the teaser
  build_site.py             manifest -> index.html, plot data, zips
  manifest.py               typed manifest (pydantic)
```

## Rebuild

The tools read the Sim2sim results read-only (default `../Sim2sim`) and the real
clips from the CADP folders on the secondary disk.

1. Render the vehicle-mounted views (CARLA 0.9.16 running on `localhost:2000`).
   The script runs Sim2sim's renderer unchanged and writes to `_work/render/`,
   so the reviewed renders are not touched:

   ```bash
   cd ../Sim2sim
   python3.11 ../real2carla-gfp/tools/render_extra_views.py \
       --videos "Video 108,Video 114" --out ../real2carla-gfp/_work/render
   python3.11 carla_safe.py --quiet
   ```

2. Encode, compose the teaser and build:

   ```bash
   uv run tools/encode_clips.py
   uv run tools/make_teaser.py
   uv run tools/build_site.py
   python3 -m http.server 8000    # preview at http://localhost:8000
   ```

Adding an accident means one entry in `site_src/accidents.yaml`; the build
checks it against the scenario's collision type, the reviewer's rating and the
clip frame counts.
